Agentic Observability Cheat Sheet

Quick reference for Antigravity streaming telemetry, Arize Phoenix, and OpenTelemetry schemas.

1. The 3-Tier Architecture

[ agy CLI (--output-format stream-json) ]
         ↓ (NDJSON pipe)
[ Python OTel Forwarder (scripts/observability/telemetry_forwarder.py) ]
         ↓ (HTTP OTLP POST http://localhost:6006/v1/traces)
[ Arize Phoenix Dashboard (Docker container on port 6006) ]

2. Arize Phoenix Commands

Start Local Dashboard (Port 6006)
docker run -d --name phoenix -p 6006:6006 --restart unless-stopped arize/phoenix:latest
Verify & Open Dashboard
# Check daemon container
docker ps --filter "name=phoenix"

# Web UI URL
http://localhost:6006
OTel Ingestion Endpoint
# OTLP HTTP Traces URL:
http://localhost:6006/v1/traces

3. Antigravity CLI Telemetry Command

agy --output-format stream-json --dangerously-skip-permissions --print "Your prompt here" \
  | python3 scripts/observability/telemetry_forwarder.py 2>&1 | tee agent-output.log

4. Stream JSON Event Types

Event Type State Key Payload Fields
init Session - conversation_id, tools list, cwd
step_update agent_response DONE duration_seconds, usage.input_tokens, usage.output_tokens
step_update tool ACTIVE tool_name, tool_info.parameters (args)
step_update tool DONE duration_seconds, tool_info.output
result Turn Result - status, duration_seconds, usage.total_tokens

5. OpenInference Span Kinds

Phoenix categorizes operations using the openinference.span.kind attribute:

  • AGENT: Top-level conversation or task execution.
  • LLM: Model generation steps, token counts, and latency.
  • TOOL: Tool calls (e.g. run_command, view_file, MCP tools).

Self-Hosted Runner Cheat Sheet

Quick-reference commands, architecture, service management, and workflow routing.

1. Architecture & Networking

Self-hosted runners use outbound long-polling over HTTPS (port 443) to GitHub. No inbound open ports, public IP, or firewall ingress rules are required.

[ Local Machine Runner ]  ---(Outbound HTTPS 443)--->  [ GitHub Actions Backend ]
                                 Polls for queued jobs
                                 Streams console logs

2. Provisioning & Registration

A. Directory Setup & Download (x64 Linux)
mkdir -p ~/actions-runner && cd ~/actions-runner
curl -o actions-runner-linux-x64-2.337.0.tar.gz -L https://github.com/actions/runner/releases/download/v2.337.0/actions-runner-linux-x64-2.337.0.tar.gz
tar xzf ./actions-runner-linux-x64-2.337.0.tar.gz
B. Fetch Registration Token via GitHub CLI
# Generate 1-hour ephemeral registration token
gh api --method POST repos/Deepakeon/expensse-summary/actions/runners/registration-token --jq .token
C. Configure Runner
./config.sh --url https://github.com/Deepakeon/expensse-summary --token <REGISTRATION_TOKEN>

3. Execution Modes

Foreground Interactive (Debug / Testing)

cd ~/actions-runner
./run.sh

Background Systemd Service (Persistent)

cd ~/actions-runner
sudo ./svc.sh install $USER    # Install service for current user
sudo ./svc.sh start           # Start runner daemon
sudo ./svc.sh status          # Check systemd status
sudo ./svc.sh stop            # Stop runner daemon
sudo ./svc.sh uninstall       # Remove systemd unit

4. Workflow Routing Syntax

Standard GitHub Actions

jobs:
  agent:
    runs-on: self-hosted       # Targets any available self-hosted runner
    # Or match multiple labels:
    # runs-on: [self-hosted, linux, x64]

GitHub Agentic Workflows (gh-aw Frontmatter)

---
name: Bug Resolver
runs-on: self-hosted
engine:
  id: gemini
  version: "0.43.0"
...
---

Recompile workflow lockfiles after updating frontmatter:

gh aw compile

5. De-registration & Cleanup

# Obtain removal token
REMOVE_TOKEN=$(gh api --method POST repos/Deepakeon/expensse-summary/actions/runners/remove-token --jq .token)

# Stop service and remove configuration
sudo ./svc.sh stop && sudo ./svc.sh uninstall
./config.sh remove --token $REMOVE_TOKEN

6. Security Guardrails

Warning: Host Compromise Risk Jobs on self-hosted runners execute with your local user privileges and environment access. Never run workflows triggered by untrusted public fork pull requests (pull_request_target or unvetted PRs). Restrict workflow triggers to repository members or manual dispatch.

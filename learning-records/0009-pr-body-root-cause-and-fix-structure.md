# Structured PR Body with Root Cause and Fix Details

Automated pull requests generated by the Antigravity runner now enforce a structured template: `Closes #<id>`, followed by `## Why Was It Happening (Root Cause)` and `## What Was the Fix (Solution & Verification)`. The agent compiles this into `pr-summary.md` during execution, which the workflow injects into `gh pr create --body`.

## Evidence
Updated `.github/workflows/antigravity-fix.yml` to instruct `agy` to output `pr-summary.md` with root cause analysis and solution verification. Existing PR #4 was updated retroactively with the exact diagnosis and fix details for Issue #1.

## Implications
Every future PR opened by the runner directly links the triggering issue, documents the diagnosed defect, and explains the verified solution.

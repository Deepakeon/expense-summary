Lesson 0008 • Observability & Logging

Comprehensive Agent Log Capture

Publishing formatted agent execution logs to GitHub Actions Step Summaries, artifacts, and issue comments.

The Three Visibility Channels

In antigravity-fix.yml, all output from agy is now captured through three separate channels:

1. GitHub Actions Step Summary (Web UI Overview)

Using tee agent-output.log and writing to $GITHUB_STEP_SUMMARY, the entire agent diagnosis report renders directly on the run overview page in an expandable dropdown:

echo "## 🤖 Antigravity Agent Execution Report" >> $GITHUB_STEP_SUMMARY
echo "<details><summary>Click to view complete agent execution output</summary>" >> $GITHUB_STEP_SUMMARY
cat agent-output.log >> $GITHUB_STEP_SUMMARY
echo "</details>" >> $GITHUB_STEP_SUMMARY
2. Downloadable Workflow Artifact

The raw log is uploaded via actions/upload-artifact@v4 with if: always() so you can download the full text log even if a step encounters errors:

- name: Upload Agent Execution Logs
  if: always()
  uses: actions/upload-artifact@v4
  with:
    name: antigravity-logs-issue-${{ github.event.issue.number }}
    path: agent-output.log
3. Automated Issue Comment

When the agent finishes and pushes the fix branch, it comments directly on the triggering issue with the PR link:

gh issue comment "$ISSUE_NUMBER" --body "🤖 **Antigravity Runner** opened pull request $PR_URL. Check Actions Step Summary for full test and diagnosis logs."

Update & Push Workflow

Push the logging enhancements to main:

git add .github/workflows/antigravity-fix.yml
git commit -m "feat(ci): add step summary, artifact upload, and issue notification"
git push origin main

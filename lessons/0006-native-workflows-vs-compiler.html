Lesson 0006 • Workflow Architecture

Native Workflows vs. gh-aw Compiler

Why gh aw compile reported no files, and why your native YAML workflow needs no compilation.

Why gh aw compile Showed an Error

The error message:

✗ no workflow markdown files found in .github/workflows

This happens because gh aw compile only searches for Markdown workflows (*.md) that need to be transformed into Actions YAML (*.lock.yml).

No Compilation Needed antigravity-fix.yml is a native GitHub Actions YAML file. GitHub Actions reads and executes .yml files natively. You do not need to run gh aw compile!

Next Step: Commit & Push to GitHub

Remove the old deleted files and push the native workflow to main:

git add -A
git commit -m "feat(ci): switch to native Antigravity runner workflow"
git push origin main

Run & Test

  1. Start your runner listener in terminal: 
    cd ~/actions-runner && ./run.sh
  2. Comment /fix on any GitHub issue.
  3. Your runner will pick up the job and execute agy directly with the diagnosing-bugs skill.

agy Execution & Diagnosing-Bugs Skill Activation

How Antigravity activates /diagnosing-bugs, approves tool actions, and autonomously resolves issues.

Does it invoke diagnosing-bugs? YES.

In antigravity-fix.yml, we configured the runner to execute:

agy --dangerously-skip-permissions --print "/diagnosing-bugs Resolve issue #$ISSUE_NUMBER: $ISSUE_TITLE..."

Because we linked ~/.agents/skills/diagnosing-bugs into ~/.gemini/config/skills/, Antigravity CLI recognizes /diagnosing-bugs as an active slash command. When agy starts, it expands the full diagnosing-bugs runbook directly into the agent's instructions.

What Happens Step-by-Step When You Comment /fix

  1. Webhook Arrival: GitHub dispatches an issue_comment event to your runner.
  2. Job Acquisition: Your local runner daemon (~/actions-runner) picks up the antigravity-fix job via outbound HTTPS poll.
  3. Repo Preparation: Runner checks out your code and sets up Node 22.
  4. CLI Launch: Runner executes agy --dangerously-skip-permissions --print "/diagnosing-bugs ..." as your local Linux user.
  5. Diagnosis Loop (Matt Pocock):
    • Phase 1 (Red Feedback Loop): The agent reads your code and writes an automated reproduction unit test in __tests__/ that fails predictably on the bug.
    • Phase 2 (Minimise): Strips down inputs to the absolute minimum required to reproduce.
    • Phase 3 (Hypotheses): Formulates 3–5 falsifiable hypotheses.
    • Phase 4 (Instrument): Adds temporary debug probes if necessary.
    • Phase 5 (TDD Fix): Applies minimal code changes in src/ and runs npm test until all unit tests pass green.
  6. Auto-Approval: The --dangerously-skip-permissions flag automatically approves file modifications and test commands, ensuring non-interactive completion.
  7. Git Branch & PR: The agent commits the solution, pushes fix/issue-<number>, and completes the workflow.
